# VALMORE — Voltra One

A responsive two-page product website for VALMORE's illustrative electric-vehicle battery concept. Built with semantic HTML, custom CSS, and vanilla JavaScript; no CSS framework or build step is required.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server. For example, from this folder:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Pages

- `index.html` — brand landing page, image slider, product overview, illustrative metrics, and quote request form.
- `produk.html` — Voltra One benefits, inline SVG architecture diagram, example specifications, vehicle integration notes, and FAQ.
- `style.css` — responsive design system and page styles.
- `script.js` — slider controls, mobile navigation, and quote form mailto handoff.
- `assets/` — optimized local product and landscape photography extracted from the provided design references.

The product values shown are concept examples only. Final specifications and compatibility require engineering validation and vehicle integration review.
